# Documentation review

Use this checklist at commit time (also summarized in [../../Agent.md](../../Agent.md)):

- [ ] `docs/index.md` links cover new topics.
- [ ] Architecture pages match process/IPC/lifecycle if those changed.
- [ ] Module pages list correct goals, boundaries, and source paths.
- [ ] Platform pages show accurate implementation status.
- [ ] ADRs added for durable decisions; index updated.
- [ ] Validation status tiers are honest (implemented / compiled / auto-tested / real-env).
- [ ] No handwritten source comments introduced.
- [ ] Keepers remain for intentionally empty directories.
