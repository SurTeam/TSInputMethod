# Documentation principles

1. **Docs live under `docs/`.** Root README is navigation only.
2. **Index first.** `docs/index.md` is the map; keep links current.
3. **Honest status.** Use implemented / compiled / auto-tested / real-env without inventing results.
4. **ADRs for durable choices.** Record rejected alternatives when they were seriously considered.
5. **Agents follow Agent.md.** Commit-time review checklist applies to every change set that touches behavior or layout.
